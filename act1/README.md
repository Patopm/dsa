# Instrucciones

1. Desarrolla un programa en Java que implemente diferentes tipos de listas enlazadas (simplemente enlazadas, doblemente enlazadas y circulares) y asegúrate de que realice operaciones básicas sobre estas estructuras.

2. El programa permitirá al usuario seleccionar el tipo de lista, insertar elementos de diferentes tipos de datos, eliminar elementos, buscar elementos y mostrar los elementos de la lista.

3. Crea cuatro clases: Node, LinkedList, DataTypeExamples, y Main.

   - Node representará un nodo en la lista.
   - LinkedList gestionará las operaciones en la lista.
   - DataTypeExamples incluirá métodos para demostrar el uso de diferentes tipos de datos.
   - Main será el punto de entrada del programa para interactuar con el usuario.

4. Implementa métodos en la clase LinkedList para manejar nodos de diferentes tipos de datos:

   - Ejemplos de tipos de datos: En la clase DataTypeExamples, implementa métodos que utilicen tipos de datos primitivos, complejos y abstractos, mostrando su aplicación práctica en contexto con las listas.

5. Utiliza la clase Main para crear un menú interactivo donde los usuarios puedan elegir el tipo de lista, realizar operaciones, interactuar con ejemplos de tipos de datos y ver los resultados en tiempo real.

6. Implementa un sistema sencillo de gestión de contactos utilizando listas enlazadas, donde cada contacto es un objeto que incluye información como nombre, dirección y número de teléfono (ejemplo de tipo de dato complejo y abstracto).
