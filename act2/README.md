# Instrucciones

1. Revisa y ajusta el código de listas ligadas entregado en la Actividad 1, asegurándote de que la implementación sea adecuada para ser utilizada en las estructuras de pilas y colas.
2. Implementación de pilas y colas:
  - Implementa las clases Pila y Cola utilizando las listas ligadas.
  - Codifica métodos para operaciones básicas como agregar (Push/Enqueue), remover elementos (Pop/Dequeue) y verificar el tope de la Pila o de la Cola (Peek).
3. Integración y pruebas:
  - Integra las estructuras de datos en un módulo de gestión de sistema operativo simulado.
  - Realiza pruebas para verificar la funcionalidad y detectar errores en el código.
